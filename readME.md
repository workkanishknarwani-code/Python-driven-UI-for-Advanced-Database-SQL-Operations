This project is a full-stack Inventory & Supply Chain Management system that combines MySQL (Backend Database), Advanced SQL (Stored Procedures, Views, Transactions), Python (MySQL Connector) and Streamlit(Web UI Frontend). The application enables non-technical end users to interact with a relational database through a clean web interface — without writing SQL queries.
Key features of this project are Dashboard & Reporting(Real-Time KPIs, Inventory summary views, Product history tracking), Inventory Operations(Add new product(via stored procedure), Place reorder, Receive reorder(transaction-based update) etc.), Data Integrity(Add new product (via stored procedure),Place reorder, Receive reorder(transaction-based update))
Advanced SQL used - Joins, Subqueries, Aggregations, Stored Procedures, Transactions (START TRANSACTION / COMMIT), Business logic inside SQL
