# Python-Driven UI for Advanced SQL Database Operations

## Overview
This project is a full-stack Inventory & Supply Chain Management system that combines:

- **MySQL** (Backend Database)
- **Advanced SQL** (Stored Procedures, Views, Transactions)
- **Python (MySQL Connector)**
- **Streamlit (Web UI Frontend)**

The application enables non-technical users to interact with a relational database through a clean web interface — without writing SQL queries.

---

## Key Features

### Dashboard & Reporting
- Real-time KPIs
- Inventory summary views
- Product history tracking

### Inventory Operations
- Add new product (via stored procedure)
- Place reorder
- Receive reorder (transaction-based update)
- Automatic stock updates
- Shipment tracking

### Advanced SQL Concepts Used
- Joins
- Subqueries
- Aggregations
- Stored Procedures
- Transactions (`START TRANSACTION / COMMIT`)
- Business logic inside SQL
